# 夜の航路 — Celestial Flight

初代 **VITURE Pro（Pro 2ではありません）** とChromeのための、ローカルで楽しむ星空・プラネタリウムアプリです。グラスなしでもマウスで操作できます。

- 実在恒星118,216個、88星座の線・日本語名・白黒図、夏の大三角
- 日本語音声に合わせ、構成星を1つずつ表示して線で結ぶガイド
- 静かな鑑賞、前進、連続飛行、星座と恒星のツアー、オリジナル音楽12曲
- 日時・場所による地上観測、時間の早送りと巻き戻し、月の満ち欠けと朝夕の空
- 8惑星の軌道と自転、表面画像、土星の環
- WebHIDによる3DoF、Full SBS表示、約80％の画面内に収める案内表示

## 起動（macOS）

1. このリポジトリを取得します。
2. Python 3.12で `python3.12 setup_voice.py` を実行すると、自然な日本語音声を準備できます。初回のみPyPIとHugging Faceから依存パッケージとKokoroモデルをダウンロードします。モデル・音声キャッシュ・実行環境はGitには含めません。
3. `outputs/星空を開く.command` をダブルクリックします。Chromeで `http://localhost:8765/` が開きます。
4. グラスを使う場合は「設定 → グラス」で接続します。

星空だけなら音声準備前でも利用でき、音声設定の「Macの読み上げ」も選べます。起動中のターミナルは開いたままにしてください。

詳しい操作・表示の近似・出典は [使い方](outputs/使い方.md) を参照してください。120Hz対応の表示設定とアプリが実際に描画できる速度は異なります。実機での装着感・左右表示・首の動きは別途確認が必要です。

## 音声データ

自然な日本語音声はKokoroでMac内に生成します。初回の準備後は外部音声サービスへ文章を送りません。音声環境は一時領域で展開し、再起動などで消えた場合は `work/voice-bundle.tar.gz` から復元します。`work` フォルダは保持してください。別のMacではセットアップを再実行します。

## 開発

Node.js 22 以上が必要です(テストと整形のみ。アプリ本体の実行には不要です)。

```bash
npm install        # 初回のみ
npm test           # work/verify-*.mjs をすべて実行
npm run format     # Prettier で整形(コミット前に実行)
```

- サーバーは `outputs/server.py` です。静的ファイルは `Cache-Control: no-cache` で配信するため、JS を編集して再読み込みするだけで反映されます。
- 8765番が他のアプリに使われている場合は、8767〜8776番に自動で切り替わります。
- 生成した音声は `outputs/narration/` に保存され、合計が 1500MB を超えると古いものから削除されます。`CELESTIAL_NARRATION_MAX_MB` で上限を変えられます。

## 検証

`npm test` で確認用スクリプト(`work/verify-*.mjs`)をまとめて実行できます。ブラウザ表示・頭の追従・音声の聴き取りはChromeで確認してください。

星表・画像・ライブラリ・音声モデルのライセンスと出典は `outputs/*LICENSE*`、`outputs/*CREDITS*` に記載しています。星座図にはFree Art Licenseの画像、基準星の配置にはCC BY-SA 4.0の派生データを含みます。
